# Data Loss Prevention (DLP) | Políticas de seguridad de la información

**Proyecto académico de ciberseguridad — 4Geeks Academy**

## Descripción

Proyecto orientado al diseño de políticas de prevención de pérdida de datos (*Data Loss Prevention — DLP*) para proteger la información sensible de una organización.

El trabajo aborda la clasificación de la información, la gestión de accesos, el principio de mínimo privilegio y la definición de controles para reducir el riesgo de divulgación o extracción no autorizada de datos.

## Objetivos

- Definir políticas para proteger información confidencial.
- Establecer criterios de clasificación de datos según su sensibilidad.
- Aplicar el principio de mínimo privilegio a la gestión de accesos.
- Considerar mecanismos de monitoreo, auditoría y prevención de fugas.
- Abordar la restricción de dispositivos USB como medida de protección de información.

## Áreas de seguridad abordadas

**Clasificación de información:** diferenciación de datos públicos, internos y sensibles para establecer medidas de protección acordes a su criticidad.

**Control de acceso:** definición de permisos y responsabilidades, aplicando el principio de mínimo privilegio.

**Prevención de fuga de datos:** análisis de controles destinados a reducir el riesgo de exposición de información.

**Monitoreo y concientización:** consideración de mecanismos de seguimiento, auditoría y buenas prácticas para usuarios.
